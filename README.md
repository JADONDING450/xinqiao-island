# 心栖小岛 · 全平台网页版

一座会呼吸的小岛：白天收着你的三个瞬间，晚上替你留着灯。

**在线访问：https://jadonding450.github.io/xinqiao-island/**

手机、电脑、平板任意设备的浏览器打开即用；支持"添加到主屏幕"（PWA），可离线使用。
不用注册、不用登录，**所有数据只保存在你自己的浏览器本地存储里**——这个项目没有服务器，技术上就传不出去。

## 功能

- **三件小事**：每天三行字 + 情绪打分（1-10），生成 14 天趋势与心情日历
- **心栖小屋**：把说不出的话写下来，收到一条来自预置内容库的回响（非真人回复）
- **放松岛**：4-7-8 呼吸、戳泡泡、记忆翻牌（刻意不计时、不计分、不排名）
- **背景轻音乐**：三首 Web Audio 实时合成的曲子（海岛晨曦 / 极光夜航 / 雨天小屋），零版权风险
- **桌宠**：可拖动、可换、可改名，只对你的操作作反应
- **安全**：12356 心理援助热线一键拨打；本机识别高风险表达时立即展示求助资源

## 设计原则（为什么这样做）

- **日签只按日期选**，不按情绪分数推——按分数推送就构成"基于健康状态的个性化内容"
- **桌宠不判断情绪状态**，只对用户的操作（保存、抚摸、点击）作反应
- **小游戏不产生任何健康数据**，只计数
- **危机分级（L0-L3）**：高风险表达 → 本机静默展示资源卡或温和干预页；干预页绝不无限拦截
- **诚实优先**：界面不渲染任何虚构的"在线人数/全球计数"；承诺"只存本机"就真正做到（无后端）

在应用内「设置 → 标注与演示」打开**合规标注**，可在界面上逐处看到这些设计依据。
危机分级演示开关（强制 L1-L3）也在那里，供评审演示干预流程；日常使用时由内容自动识别。

## 本地运行

这是一个纯静态站点。直接双击 `index.html` 即可；或任意静态服务器托管（如 `python -m http.server`）。
`index.html` 是完全自包含的单文件（图片已内嵌），拷走一个文件就能用。

## 数据与隐私

- 存储：浏览器 `localStorage`（前缀 `xz_`），可随时在「我 → 隐私 → 删除本机记录」一键清空
- 导出：「我 → 数据 → 导出我的数据」生成 JSON 文件
- 无账号体系、无网络请求携带用户内容、无第三方统计
